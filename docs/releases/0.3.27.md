# Workbench 0.3.27

- 图片预览支持缩放按钮、滚轮和快捷键；可以切换适应窗口、查看缩放比例，并拖动放大的图片。
- 改进终端输出高亮及控制序列处理，保持输出内容和工具面板样式一致。
- Agent 接入共享执行栈。首轮工具集遵循项目和 Mod 的可见性规则，请求使用实际工具 schema，调用与结果保留同一身份。
- 行内补全使用统一模型请求客户端，由 Workbench 持有光标上下文、输出限制和结果处理。

本版采用正式 Platform 包：Agent `0.6.9`、Model `0.5.0`、Browser `0.2.16`、Development `1.1.0`、Project `2.0.8`、System `1.1.5`。
