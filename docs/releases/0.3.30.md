# Workbench 0.3.30

- 对齐 Platform 0.6.17 的工具安全边界：浏览器页面脚本安全编码外部输入，Windows 命令解释器使用受控系统路径，破坏性命令识别覆盖大小写和组合参数。
- 强化 Office 预览净化：基于标准 HTML 解析器执行标签、属性、链接协议白名单，同时保留受限的内嵌栅格图片；演示文稿运行时补充安全随机数和归档媒体路径校验。
- 优化会话搜索性能：路径提示改为线性扫描，消除超长输入造成的正则回溯，并修正 JSON、JavaScript 和 Java 等相邻扩展名的误识别。
- 提升兼容性：保留结构化输出围栏、上下文命令锚点和浏览器性能摘要的既有输入形态，并收紧跨平台路径、模型别名和工具结果解析的一致性。
