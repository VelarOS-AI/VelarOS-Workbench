# Workbench 0.3.28

- 升级共享 Platform 执行栈：Agent `0.6.10` 提供稳定的 runtime/host 入口、修正运行取消语义；Model `0.6.0` 将结构化输出类型绑定到 schema；Development `1.1.1` 收窄语言操作的运行时依赖边界。
- 同步 Browser `0.2.17`、Project `2.0.9` 和 System `1.1.6`，使 Workbench 的 Platform 依赖图共用 Agent `0.6.10` 兼容约束。
- 重构更新发布事务：分发平台回执记录真实系统、架构、签名状态和验证证据；发布前校验暂存字节，上传后校验远端字节与签名目录，最后写入 completion 回执。
- 优化生产启动路径：main 入口仅在生产构建时压缩，IDE 工作区在打开项目后按需加载。main 入口由 6.37 MB 降至 3.35 MB，renderer 启动入口由 5.06 MB 降至 3.33 MB。
- 新增构建体积预算门，按 `index.html` 实际引用统计启动 JS/CSS，并同时限制 main、renderer 总体积与最大功能块，防止启动成本回归。

本版采用正式 Platform 包：Agent `0.6.10`、Model `0.6.0`、Browser `0.2.17`、Development `1.1.1`、Project `2.0.9`、System `1.1.6`、Core `0.4.0`、Kernel `0.2.1`、UI `0.2.29`。
